## サービス名
# OBIMOTO（オビモト）　　

## サービス概要
"OBIMOTO"は就活生や転職者の気になる業界、企業のリアルな情報を公開、共有できるSNS型情報収集アプリです.  

## このサービスへの思い、作りたい理由
学生時代の就職活動中にて、気になる業界や企業のリアルな雰囲気を知りたいと思い、自分で既存の就活サイトや口コミサイトみたり、OB訪問をしたりしましたが、既存のサイトでは自分のピンポイントで知りたいと思った情報がなかったり、OB訪問においても対応してくれるOBそもそもその企業の採用に関わる一要員としてのあたり触りのない建前の回答ばかりで自分が本当に知りたいところははぐらかされたりしたという経験がありました。    

そんな中、RUNTEQという環境で様々なイベントなどで先輩方の赤裸々に話してくれる環境を見て、なぜこうも忖度なく、建前抜きに時にはオフレコでみたいな話してくれるのかというところを考えました。
その結果、私は
`『同じ環境や同じ志を持ったコミュニティに属している、または属していたという繋がりによって人はオープンに正直なことを話せるし、話してもいいかなと思えるのではないか`という結論にいたりました。　　

しかし、一方でそのような共通の繋がりがあったとしても自分の気になる業界や会社で働く人が都合よく自分の関われる範囲（例：期が近いなど）でいるかというとそういったケースは稀でしょう。  
そこで今回、そのような`共通のコミュニティに属する（属していた）直接面識のない人同士でも繋がれて、有益な情報開示、交換ができる環境を提供するアプリ`ができたらいいなと思い、このアプリを作ろうと考えました。

裏の理由としては、学生時代に所属していたサークルの現役の後輩たちと交流する場があった時に、それまで面識なくても忖度なくアドバイスしあっている仲間を見たの、現役の学生たちが就活で気軽に質問できる環境がほしいという思いを聞いたため作ろうと思ったことがきっかけです。

## ユーザー層について
想定ユーザーは`質問者`と`回答者`というそれぞれ存在します。
- 直近の開発での想定ユーザー
  - 質問者：転職、就職を考えているRUNTEQ生
  - 回答者：すでに転職したRUNTEQ OBOG　　

- 将来的なユーザー
  - 質問者：RUNTEQ生に関わらない就活、転職希望者
  - 回答者：会社にすでに所属している社会人

## サービスの利用イメージ. 
利用イメージは質問者、回答者でそれぞれ異なるユースケースを想定しています。

- 質問者側の利用イメージ
  - 気になる業界、企業の本音ベースの情報を知りたい時に活用する。（就活転職活動のための情報収集目的）
- 回答者側の利用イメージ
  - 自分の属している業界、企業の紹介を通じて、同じ業界に属する仲間づくりのきっかけとして活用する。（宣伝目的）
  - 他社と自社との比較などを行う。
- 質問者、回答者どちらに対してもこのアプリが提供するものはあくまでに`環境`です。  
`忖度ない意見、情報を共有し合えるような人とつながりやすい環境`も提供することがこのアプリの主目的となります。  そこで得られた情報はあくまでも副次的な提供物となります。

## ユーザーの獲得について
▫️想定ユーザーごとに提供するサービス
- 直近の開発における想定ユーザーに対して. 
  - 各期のコミュリにアポを取り、本アプリの詳細宣伝をして、普及を促す。   
  - 実際のイベントなどに参加し、宣伝する。  
  上記の宣伝を行いつつ、アプリに対する意見、コメントなどをもらい、本リリのアップデートに繋げる。

▫️現状考えるサービスの課題：
- 情報の提供元がユーザーになるため、ユーザーが増えるまではユーザーが価値を感じづらい状況が続いてしまう点。   
  →初期にはユーザーがいなくても企業情報などのNewsとして発信し、その情報を提供物としておくことで初期ユーザーの不満点の軽減を諮る。

## サービスの差別化ポイント・推しポイント
既存のサービスには OpenWorksやリクナビ、Matcherなどがありますが、これらとの決定的な違いは共通のコミュニティーに属すると言う繋がりによる`信頼感`や`安心感`など心理的安全性が高いことが差別化のポイントとなると感じています。（よってそのためには信頼感、安心感を損なう要素（関わりのない不特定多数のユーザーが同じコミュニティーの環境下にアクセスできないようにしたり、アカウント通報機能などを設けるなどの対策が必要）

## 機能候補
以下、実装予定の機能一覧
- 基本機能（MVPで実装予定）
  - ユーザー登録機能（ユーザー名、メールアドレス、パスワードで作成）
  - 新規コミュニティ作成機能
  - コミュニティ検索および所属申請機能（各コミュニティごとにパスワード設定）
  - コミュニティ詳細設定機能（コミュニティオーナーのみ利用可能。期ごとのグルーピングをしたら、オーナー権限を付与したりする機能）
  - 自己プロフィール作成機能（コミュニティ内のみで開示、コミュニティごとに設定可能）
  - 企業、業界検索機能（コミュニティを横断して、検索可能）
  - 企業情報掲示機能（コミュニティを横断して、公式のHPなどの情報をアプリ側が提供、初期ユーザーへの価値提供のため）
  - ユーザー間チャット機能（コミュニティ内のユーザー同士で承認しあった場合のみ可能）
  - 企業、業界からユーザーを検索する機能（コミュニティ内の該当のユーザーのみ検索ヒットする）
  - (企業、業界紹介文投稿機能（ユーザーがコミュニティ内に発信する自社の職場紹介などを投稿する機能）)
  - ユーザーへの”いいね”、”ありがとう"などのSNS　Like/リアクション機能
  - チャット相談人数制限機能（回答者側になった際に回答することが負担にならないようにする仕組み）
  
- アップデート機能（本リリまでに実装予定）
  - お気に入りユーザー設定機能
  - 関心のある業界、業種設定機能（気になる業界や業種の企業情報や投稿が優先的に表示されるようにする機能）
  - チャット相談お礼ポイント（Nice OB Point）付与機能（チャットなどのお礼代わりに付与されるポイント、相談の順番スキップなどに活用）
  - 投稿ポイント付与機能（企業職場紹介投稿をすると付与されるポイント、Nice OB Pointよりも配当ポイントを高く設定する。活用はNice OB Pointと同様）
  - ポイント集計機能
