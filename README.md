## サービス名
# OBIMOTO（オビモト）　　

## サービス概要
"OBIMOTO"は就活生や転職者の気になる業界、企業のリアルな情報を公開、共有できるSNS型情報収集アプリです.  

## このサービスへの思い、作りたい理由
学生時代の就職活動中にて、気になる業界や企業のリアルな雰囲気を知りたいと思い、自分で既存の就活サイトや口コミサイトみたり、OB訪問をしたりしましたが、既存のサイトでは自分のピンポイントで知りたいと思った情報がなかったり、OB訪問においても対応してくれるOBそもそもその企業の採用に関わる一要員としてのあたり触りのない建前の回答ばかりで自分が本当に知りたいところははぐらかされたりしたという経験がありました。    

そんな中、RUNTEQという環境で様々なイベントなどで先輩方の赤裸々に話してくれる環境を見て、なぜこうも忖度なく、建前抜きに時にはオフレコでみたいな話してくれるのかというところを考えました。
その結果、私は
`『同じ環境や同じ志を持ったコミュニティに属している、または属していたという繋がりによって人はオープンに正直なことを話せるし、話してもいいかなと思えるのではないか`という結論にいたりました。　　

しかし、一方でそのような共通の繋がりがあったとしても自分の気になる業界や会社で働く人が都合よく自分の関われる範囲（例：期が近いなど）でいるかというとそういったケースは稀でしょう。  
そこで今回、そのような`共通のコミュニティに属する（属していた）直接面識のない人同士でも繋がれて、有益な情報開示、交換ができる環境を提供するアプリ`ができたらいいなと思い、このアプリを作ろうと考えました。

裏の理由としては、学生時代に所属していたサークルの現役の後輩たちと交流する場があった時に、それまで面識なくても忖度なくアドバイスしあっている仲間を見たことと、現役の学生たちが就活で気軽に質問できる環境がほしいという思いを聞いたため作ろうと思ったこともきっかけとなっています。

## ユーザー層について
想定ユーザーは`質問者`と`回答者`というそれぞれ存在します。
- 直近の開発での想定ユーザー
  - 質問者：転職、就職を考えているRUNTEQ生
  - 回答者：すでに転職したRUNTEQ OBOG　　

- 将来的なユーザー
  - 質問者：RUNTEQ生に関わらない就活生や転職希望者
  - 回答者：共通のコミュニティというつながりを持った会社にすでに所属している社会人（初期は自分の出身校のサークルのOBOGに声がけを行い、参加してもらいます）
  - 初期は自信の出身校のサークルからサービスを開始を考えており、質問者には現役生、回答者にはそのサークルのOB OGを考えています。（個人的な伝手で各期の代表を通じて、賛同者に参加してもらうように宣伝をしていきます。）

## サービスの利用イメージ. 
利用イメージは質問者、回答者でそれぞれ異なるユースケースを想定しています。

- 質問者側の利用イメージ
  - 気になる業界、企業の本音ベースの情報を知りたい時に活用する。（就活転職活動のための情報収集目的） 
  
- 回答者側の利用イメージ 
  - 自分の属している業界、企業の紹介を通じて、同じ業界に属する仲間づくりのきっかけとして活用する。（宣伝目的）
  - 他社と自社との比較などを行う。  
  
- 質問者、回答者どちらに対してもこのアプリが提供するものはあくまでに`環境`です。  
`忖度ない意見、情報を共有し合えるような人(共通のコミュニティというつながりを持った直接面識のない人同士）がつながりやすい環境`も提供することがこのアプリの主目的となります。   
そこで得られた情報はあくまでも副次的な提供物となります。

## ユーザーの獲得について
▫️想定ユーザーごとに提供するサービス
- 直近の開発における想定ユーザーに対して. 
  - 各期のコミュリにアポを取り、本アプリの詳細宣伝をして、各期の方に宣伝いただけないか交渉するなどして普及を試みる。   
  - 実際のイベントなどに参加し、宣伝する。  
  上記の宣伝を行いつつ、アプリに対する意見、コメントなどをもらい、本リリのアップデートに繋げる。

▫️現状考えるサービスの課題：
- 情報の提供元がユーザーになるため、ユーザーが増えるまではユーザーが価値を感じづらい状況が続いてしまう点。   
  →初期にはユーザーがいなくても企業情報などのNewsとして発信し、その情報を提供物としておくことで初期ユーザーの不満点の軽減を諮る。

## サービスの差別化ポイント・推しポイント
既存のサービスには OpenWorksやリクナビ、Matcherなどがあります。   
これらとの決定的な違いはあえて共通のコミュニティーに属するまたは属したことがあるというような直接質問できるユーザー範囲を絞ることで、質問者側・回答者側の双方に対して、`信頼感`や`安心感`などという心理的安全性高めるという点が差別化のポイントとなるとなります。（よってそのためには信頼感、安心感を損なう要素（関わりのない不特定多数のユーザーが同じコミュニティーの環境下にアクセスできないよう、コミュニティ参加のためのゲートを設けたり、アカウント通報機能などを設けて、プライバシーに配慮した設計としています。）

## 機能候補
このアプリを利用する全てのユーザーが本アプリにおいては質問者にも、回答者にもなります。

以下、実装予定の機能一覧
- 基本機能（MVPで実装予定）
  - 全ユーザー利用可能機能
    - ユーザー登録機能（ユーザー名、メールアドレス、パスワード、社会人の場合は職歴も入力で作成）
    - 新規コミュニティ作成機能（全てのユーザーがコミュニティを作成する機能、作成されたコミュニティは全ユーザーが検索可能）
    - コミュニティ検索および参加申請機能（コミュニティ検索および各コミュニティごとにパスワードを入力し、そのコミュニティオーナーまたは参加承認権限付与されているユーザーの承認があってコミュニティへの可能となる機能）
    - 自己プロフィール作成機能（コミュニティ内のみで開示するプロフィール（コミュニティ内でのアカウント名、卒業年・期、職歴などで構成）を作成する機能、コミュニティごとに違う内容での設定も可能（コミュニティごとに個人情報の開示範囲をユーザーが設定できる仕組み）
    - 企業、業界検索機能（コミュニティを横断して、特定の企業の企業紹介ページを検索する機能）
    - 企業情報掲示機能（コミュニティを横断して、公式のHPへのリンクや企業の事業内容の情報をアプリ側が提供する機能）
    - ユーザー間チャット機能（同一のコミュニティ内に所属するユーザー同士の同意のもと１対1のチャットルームが作成されてその中でのみユーザー同士が一定期間（１週間で設定予定）チャット可能となる機能）
    - チャットルームおよびチャット自動削除機能（チャットはチャットルーム作成から１週間後にチャットルームと共に削除、`情報漏洩防止対策`として実装）
    - 相談するユーザーを検索する機能（コミュニティ内の条件に合うユーザーを検索する機能。イメージは企業・業界で絞るとその業界・企業に所属しているまたは所属していたユーザーが見つかる機能で個人チャットの申請に繋げる仕組み）
    - チャットお知らせ機能（チャットしている相手からのメッセージが来た際にメールにて通知する機能）
    - チャット相談人数制限機能（回答者ユーザーの負担をユーザー自信でコントロールできるようにする機能。一度に対応できる人数をユーザーが自信で制限をかけられる機能）
    - 回答拒否機能 (回答者にならないことを宣言する機能。本機能を使うと質問者になった際にチャット制限を設ける設定する)
    

  - 一部ユーザー限定機能
    - コミュニティ詳細設定機能（コミュニティオーナーのみ利用可能。作成したコミュニティの概要説明やアイコン設定（アイコン設定は本リリで実装）が可能。またコミュニティ内に期ごとのグルーピングをしたり、ユーザーのコミュニティ参加を承認する権限を他のユーザーに付与したりする機能。）
    - コミュニティ参加承認通知機能（コミュニティオーナーまたはコミュニティオーナー権限を持つユーザーのみが使える機能。コミュニティへの参加申請が来た時に通知がメールで届く機能）
    - 職場紹介投稿の編集、削除機能（職場紹介投稿をしたユーザーのみが利用可能。投稿した内容を編集・削除できる機能）
    - チャット許可承認通知機能（他のユーザーからチャット申請許可依頼が通知され、その依頼に対して承認するとチャットルームが作成される機能）
    - チャット機能停止機能（回答拒否機能を設定したユーザーまたは、一定回数（5回）以上質問チャット申請を否認したユーザーに対してチャット申請ができなくする機能）

  
- アップデート機能（本リリまでに実装予定）
  - 職場紹介文投稿機能（ユーザーがコミュニティ内に発信する自社の職場紹介などの内容を投稿する機能、投稿するとポイントが付与される機能も実装予定（別途機能にて記載））
  - お気に入りユーザー設定機能（お気に入りにユーザーを追加する機能）
  - 関心のある業界、業種設定機能（気になる業界や業種の企業情報や投稿が優先的に表示されるようにする機能）
  - チャット相談お礼ポイント（Nice OB Point）付与機能（チャットなどのお礼代わりに付与されるポイント、相談の順番スキップなどに活用できるポイント）
  - 投稿ポイント付与機能（企業職場紹介投稿をすると付与されるポイント、Nice OB Pointよりも配当ポイントを高く設定する。活用はNice OB Pointと同様）
  - ポイント集計機能
  - ユーザーアカウントブロック機能（コミュニティ内の特定のユーザーをブロックする機能。ブロックするとその相手ユーザーからは自分のアカウントが表示、検索できなくなる機能）
  - ユーザー通報バン機能（特定のユーザーのアプリ利用について通報する機能。通報先はコミュニティオーナーまたはそれに準ずる人）
