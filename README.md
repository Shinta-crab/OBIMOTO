## サービス名
# OBIMOTO（オビモト）　　

## サービス概要
"OBIMOTO"は就活生や転職者の気になる業界、企業のリアルな情報を公開、共有できるコミュニケーションアプリです.  

## このサービスへの思い、作りたい理由
学生時代の就職活動中にて、気になる業界や企業のリアルな雰囲気を知りたいと思い、自分で既存の就活サイトや口コミサイトみたり、OB訪問をしたりしましたが、既存のサイトでは自分のピンポイントで知りたいと思った情報がなかったり、OB訪問においても対応してくれるOBそもそもその企業の採用に関わる一要員としてのあたり触りのない建前の回答ばかりで自分が本当に知りたいところははぐらかされたりしたという経験がありました。    

そんな中、RUNTEQという環境で様々なイベントなどで先輩方の赤裸々に話してくれる環境を見て、なぜこうも忖度なく、建前抜きに時にはオフレコでみたいな話してくれるのかというところを考えました。
その結果、私は
`『同じ環境や同じ志を持ったコミュニティに属している、または属していたという繋がりによって人はオープンに正直なことを話せるし、話してもいいかなと思えるのではないか`という結論にいたりました。　　

しかし、一方でそのような共通の繋がりがあったとしても自分の気になる業界や会社で働く人が都合よく自分の関われる範囲（例：期が近いなど）でいるかというとそういったケースは稀でしょう。  
そこで今回、そのような`共通のコミュニティに属する（属していた）直接面識のない人同士でも繋がれて、有益な情報開示、交換ができる環境を提供するアプリ`ができたらいいなと思い、このアプリを作ろうと考えました。

## ユーザー層について
想定ユーザーは`質問者`と`回答者`というそれぞれ存在します。
- 直近の開発での想定ユーザー
  - 質問者：転職、就職を考えているRUNTEQ生
  - 回答者：すでに転職したRUNTEQ OBOG　　

- 将来的なユーザー
  - 質問者：RUNTEQ生に関わらない就活、転職希望者
  - 回答者：会社にすでに所属している社会人

## サービスの利用イメージ. 
利用イメージは質問者、回答者でそれぞれ異なるユースケースを想定しています。

- 質問者側の利用イメージ
  - 気になる業界、企業の本音ベースの情報を知りたい時に活用する。（就活転職活動のための情報収集目的）
- 回答者側の利用イメージ
  - 自分の属している業界、企業の紹介を通じて、同じ業界に属する仲間づくりのきっかけとして活用する。（宣伝目的）
  - 他社と自社との比較などを行う。
- 質問者側、回答者側どちらに対してもあくまで提供するものは忖度など反省しづらい共通の繋がりを持った人と人を繋げる環境です。環境

## ユーザーの獲得について
▫️想定ユーザーごとに提供するサービス
- 直近の開発における想定ユーザーに対して. 
  各期のコミュリにアポを取り、本アプリの詳細宣伝をして、普及を促す。   

▫️現状考えるサービスの課題：
- 情報の提供元がユーザーになるため、ユーザーが増えるまではユーザーが価値を感じづらい状況が続いてしまう点。如何に初期に多くのユーザーを獲得するかが重要となるという点。

## サービスの差別化ポイント・推しポイント
既存のサービスには OpenWorksやリクナビなどがありますが、これらとの決定的な違いは共通のコミュニティーに属すると言う繋がりや信頼や安心感が差別化のポイントとなると感じています。（よってそのためには信頼感、安心感を損なう要素（関わりのない不特定多数のユーザーが同じコミュニティーの環境下にアクセスできないようにしたり、アカウント通報機能などを設けるなどの対策が必要）

## 機能候補
以下、実装予定の機能一覧
- 基本機能
  - 新規コミュニティ作成機能
  - コミュニティ検索および所属申請機能（各コミュニティごとにパスワード設定）
  - 自己の経歴登録機能
  - 企業、業界検索機能
  - 企業、業界からユーザーを検索する機能
  - 企業、業界紹介文投稿機能
  - 情報への”いいね”、”ありがとうのSNS　Likeに/リアクション投稿機能”
