## ▫️サービス名
# OBIMOTO（オビモト）　　

## ▫️サービス概要
"OBIMOTO"は就活生や転職者の人が気になるリアルな企業、職場の情報を得られるキャリア相談アプリです.  

### 開発の目的  
既存の就職活動・転職活動での求職者が抱く情報収集に関する不安を解消します。  
- 従来の課題：  
     - OB/OG訪問での情報収集の課題：情報を提供してくれるのは学校のOB/OGではあるが、そんなOB/OGも企業の社員としての立場があるため、ポジショントークになってしまう。
     - OpenWorkなど口コミ掲載による情報収集の課題：求職者側のピンポイントで知りたい情報が見つからなかったり、追加で生まれた質問は聞くことができない.
- OBIMOTOでの解決策
  - **『部活やサークル、共通のコミュニティなどの共通の団体』という利害関係の発生しないつながりを基盤とすることで、『親しい友人を助ける』ような心理的安全性** を確保し、忖度のない、**リアルな『本音（モト）』**の情報を交換できる場を提供します。  

## ▫️開発背景
開発者自身も学生時代、OB/OG訪問では質問するけどどこか本音で話していない感じなど感じていました。また口コミサイトでも自分が聞きたいのはもっとここも知りたいんだよなという何ともモヤモヤした思いが常にありました。  
その後、社会人になってですが、高校時代の部活のOB会の席で学生時代は直接関わりはなかった10個も年の離れた先輩と話す機会がありました。その先輩の話は面白く、ついつい深掘りして色々質問をしてしまいました。結構際どい質問もしたように思います。　　
でもその先輩は心よく自分の質問に全て赤裸々に答えてくれたのです。   
この経験からバックグランドの共通の繋がりは利害関係なく、協力してもいいという心理を生むことに気づきました。  
本アプリはそんな**『共通の繋がり』**が就活者の悩みの解決に役立つと考え、開発しました。　　

## ▫️対象ユーザー　　
就活者（学生、社会人、転職希望者）
